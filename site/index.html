CursorMemo
Cursor stops forgetting.

Cursor's AI forgets everything when a chat ends. CursorMemo gives it a notebook: what you did, what failed, and what's still open — written down automatically, and read back at the start of your next session. No re-explaining, ever.

WINDOWS — PowerShell, one line

irm https://cursormemo.funapp.live/install.ps1 | iex

LINUX / macOS / WSL2 — one line

curl -fsSL https://cursormemo.funapp.live/install.sh | sh

AFTER INSTALLING

  1. Restart Cursor (or toggle the ai-memory server off/on in Settings → MCP).
  2. Open any project and ask the agent: "What do you remember about this project?"
  3. Just work as usual. The memory writes itself — and the next session picks up where you left off.
