မသုံးခင်BEFORE

  • မနေ့က ဘာလုပ်ခဲ့လဲ ပြန်မေးရင် AI က မမှတ်မိဘူး

  • Project တစ်ခု ရပ်ပြီး ပြန်လာရင် ဘယ်ရောက်နေလဲ ကိုယ်တိုင် ပြန်ရှာရတယ်

သုံးပြီးနောက်AFTER

  • မနေ့က ဘယ်မှာ ရပ်ခဲ့လဲ AI က ကိုယ်တိုင် သိနေတယ်
  • ပြန်ရှင်းပြစရာ မလိုဘူး — chat စတာနဲ့ ဆက်လုပ်တယ်
  • အဆင်မပြေခဲ့တဲ့ နည်းတွေကို မှတ်ထားလို့ ထပ်မစမ်းဘူး
  • Project တိုင်းရဲ့ မှတ်စုက သီးခြားစီ — ရောမသွားဘူး

Cursor — Chat အသစ်

AI ကို ဒီလို မေးကြည့်

"What do you remember about this project?"

မေးလို့ရတဲ့ စာတွေ

Cursor chat ထဲမှာ ဒီလိုစာတွေ ရိုက်ပြီး မှတ်စုကို ပြန်ခေါ်လို့ရတယ်။

"Where did we leave off?"

ဘယ်နေရာမှာ ရပ်ခဲ့လဲ — နောက်ဆုံး လုပ်ခဲ့တာနဲ့ ကျန်နေတာကို ပြန်ပြောပြတယ်။

"Have we discussed X?"

X အကြောင်း အရင်က ဆွေးနွေးဖူးလား — မှတ်စုထဲကနေ ရှာပြီး ပြန်ပြောပြတယ်။

"Catch me up"

အကျဉ်းချုပ် ပြောပြ — ရက်အနည်းငယ် နားပြီးမှ ပြန်လာရင် အခြေအနေကို အတိုချုပ် ရှင်းပြတယ်။

"Save context for the next session"

နောက် session အတွက် မှတ်စု ရေးထား — ရပ်ခါနီးမှာ နောက်လူ (နောက် AI) အတွက် မှတ်စု လက်ဆင့်ကမ်း ရေးပေးတယ်။

📖 မှတ်စုတွေကို ကိုယ်တိုင် ကြည့်ချင်ရင် — Browser ထဲမှာ http://127.0.0.1:49374/web ကို ဖွင့်ပါ။ မှတ်စု စာမျက်နှာတွေကို စာအုပ်လို ဖတ်လို့ရတယ်။

ဘယ်လို နည်းစနစ်နဲ့ ဖန်တီးထားလဲ

CursorMemo က အပိုင်း ၂ ပိုင်း ပေါင်းစပ်ထားတာ — နောက်ကွယ်က အင်ဂျင် (ai-memory) နဲ့ အပေါ်က ထုပ်ပိုးမှု (CursorMemo)။ တစ်ခုချင်းစီ ဘယ်လို လုပ်ထားလဲ ရှင်းပြထားတယ်။

အပိုင်း ၁ — အင်ဂျင်: ai-memory

Rust ဆိုတဲ့ programming language နဲ့ ရေးထားတဲ့ program တစ်ခုတည်း (binary တစ်ဖိုင်တည်း)။ Server သီးခြား, database သီးခြား တင်စရာ မလိုဘူး — အဲ့ဒီတစ်ဖိုင်တည်းက အကုန် လုပ်တယ်။

အလုပ်လုပ်ပုံ အဆင့် ၄ ဆင့်

1

မှတ်ယူတယ် (Capture)

Cursor ရဲ့ lifecycle hooks က session တစ်ခုလုံးရဲ့ အဖြစ်အပျက်တွေ — မင်း ဘာမေးလဲ၊ AI ဘာ tool သုံးလဲ၊ session ဘယ်တော့ စပြီး ဘယ်တော့ ပြီးလဲ — ကို တိတ်တိတ်လေး server ဆီ ပို့တယ်။

2

စစ်ပြီး သန့်တယ် (Sanitize)

မသိမ်းခင် အရင် စစ်တယ် — password, API key လို အရေးကြီးတဲ့ အရာတွေ ပါလာရင် ဖယ်ပြီးမှ သိမ်းတယ်။

3

စာမျက်နှာ အဖြစ် စုစည်းတယ် (Consolidate)

Session ပြီးတာနဲ့ အဖြစ်အပျက်တွေကို ဖတ်ရလွယ်တဲ့ markdown စာမျက်နှာတွေ အဖြစ် ပြောင်းတယ်။ ဒီစာဖိုင်တွေက မှတ်စုရဲ့ မူရင်း အရင်းအမြစ် — git နဲ့ version မှတ်တမ်း ထိန်းထားတယ်။ ရှာရမြန်အောင် SQLite database (FTS5 full-text search) နဲ့ အညွှန်း ထပ်လုပ်တယ်။

ပြန်ရှာပြီး လက်ဆင့်ကမ်းတယ် (Recall + Handoff)

နောက် session စတာနဲ့ ရှေ့ session ရဲ့ အကျဉ်းချုပ်ကို AI ဆီ အလိုအလျောက် ပို့ပေးတယ်။ AI က လိုရင် မှတ်စုထဲမှာ full-text search နဲ့ အသေးစိတ် ထပ်ရှာလို့ရတယ်။ အခြေခံ ပုံစံမှာ ဒီအဆင့်အားလုံး AI API လုံးဝ မသုံးဘူး — key မလိုဘူး။

အပိုင်း ၂ — ထုပ်ပိုးမှု: CursorMemo

CursorMemo ကိုယ်တိုင်က code အသစ် မဟုတ်ဘူး။ သူများတွေ အလွယ်တကူ တင်သုံးနိုင်အောင် လုပ်ထားတဲ့ ထုပ်ပိုးမှုပဲ။

📦

Installer scripts

Windows အတွက် PowerShell script, Linux/macOS အတွက် Bash script။ အဲ့ဒီ script တွေက ai-memory ရဲ့ တရားဝင် installer ကို ခေါ်သုံးပြီး Cursor တစ်ခုတည်းနဲ့ပဲ ချိတ်ဖို့ setup --agent cursor ဆိုတဲ့ အမိန့်ကို run ပေးတယ်။

🌐

ဒီ website

Static web page တစ်ဖိုင်တည်း (HTML + CSS + JavaScript)။ Framework မပါ, build လုပ်စရာ မလို။ Server ပေါ်မှာ nginx နဲ့ တင်ပြီး Let's Encrypt HTTPS လက်မှတ် သုံးထားတယ်။

🐙

GitHub + MIT license

Source code အကုန်ကို GitHub မှာ public တင်ထားတယ်။ ai-memory လည်း MIT, CursorMemo လည်း MIT — ဘယ်သူမဆို အခမဲ့ သုံး, ပြင်, ပြန်ဝေလို့ရတယ်။

🔍 အကျဉ်းချုပ် — Rust program တစ်ခုတည်းက မှတ်စု server အဖြစ် ကိုယ့်စက်ထဲမှာ run တယ်။ Cursor က MCP + hooks နဲ့ ချိတ်တယ်။ မှတ်စုက markdown စာဖိုင်တွေ + SQLite အညွှန်း။ CursorMemo ကတော့ အဲ့ဒါကို တစ်ချက် install နဲ့ မြန်မာ လမ်းညွှန် ပေါင်းထည့်ထားတဲ့ ထုပ်ပိုးမှု။

မေးလေ့ရှိသောမေးခွန်းများ

လူတွေ အမေးများဆုံး မေးခွန်းတွေကို စုပြီး ရှင်းပြထားတယ်။

Project တိုင်းမှာ ထပ်တင်ရမှာလား?

မလိုဘူး။ စက်တစ်လုံးမှာ တစ်ခါတည်း တင်ရင် ရပြီ။ Installer က Cursor ရဲ့ global setting ထဲကို ရေးပေးတာမို့ ဖွင့်သမျှ project တိုင်းမှာ အလိုအလျောက် အလုပ်လုပ်တယ်။

API key သို့မဟုတ် အကောင့် လိုလား?

မလိုဘူး။ အခြေခံ ပုံစံက ဘယ် AI ဝန်ဆောင်မှုနဲ့မှ မချိတ်ဘူး။ အခမဲ့၊ အကောင့်မလို၊ အင်တာနက်တောင် မရှိလည်း မှတ်စုက အလုပ်လုပ်တယ်။ (Download လုပ်တုန်းသာ အင်တာနက် လိုတယ်။)

ငာ့ code အကြောင်းတွေ အပြင်ကို ရောက်သွားမလား?

မရောက်ဘူး။ မှတ်စုတွေ အကုန် မင်းရဲ့ ကွန်ပျူတာထဲမှာပဲ သိမ်းတယ်။ Program က မင်းရဲ့ စက်ထဲမှာပဲ run တာ။ သိမ်းခါနီးမှာလည်း password လို အရေးကြီးတဲ့ အရာတွေကို စစ်ပြီး ဖယ်ပေးတဲ့ အဆင့် ပါတယ်။

Project တွေ အများကြီး လုပ်ရင် မှတ်စုတွေ ရောကုန်မလား?

မရောဘူး။ မှတ်စုကို project တစ်ခုချင်းစီ အလိုက် folder လမ်းကြောင်းနဲ့ ခွဲသိမ်းတယ်။ Project A မှာ အလုပ်လုပ်ရင် A ရဲ့ မှတ်စုပဲ တိုးတယ်။

ဖျက်ချင်ရင် ဘယ်လိုဖျက်မလဲ?

PowerShell သို့မဟုတ် terminal ထဲမှာ ai-memory uninstall --apply လို့ ရိုက်ပါ။ Installer က တင်ခဲ့သမျှ အကုန်ကိုပဲ ဖယ်ပေးတယ် — တခြားဟာ မထိဘူး။

Cursor အပြင် တခြား AI tool တွေနဲ့ရော ရလား?

အခု CursorMemo က Cursor တစ်ခုအတွက်ပဲ ရည်ရွယ်ထားတယ်။ နောက်ကွယ်က program ကတော့ AI tool ၂၀ ကျော်နဲ့ ချိတ်လို့ရတယ် — နောက်ပိုင်း လိုအပ်ရင် ထပ်တိုးပေးမယ်။

ပိုက်ဆံ ပေးရမှာလား?

မပေးရဘူး။ CursorMemo ရော၊ နောက်ကွယ်က ai-memory ရော open source (MIT license) — အခမဲ့ သုံးနိုင်၊ ပြင်နိုင်၊ ပြန်ဝေနိုင်။
